# 文字换色、透明度与字体恢复

页面有需换肤文字时，Phase 1 前完整读取。本文定义文字透明度的最小例外及字体故障恢复；角色配色仍由《颜色决策规则》决定，对比度验收由《验收规则》第 5 节决定。

## 1. 先区分问题，不能只换 RGB

读取文字区间的 Paint Alpha、TEXT 节点 opacity、全部祖先 opacity、状态和真实背景。普通 NORMAL 合成中的有效文字强度可由各 Alpha 的乘积辅助定位，复杂混合须看实际渲染。

`100/80/60/40` 是默认层级起点，不是必须写入每段文字的 Paint Alpha。原节点已为 40% 时再写 40% Paint，可能变成约 16% 的有效强度；不能重复弱化。实际难读时检查黑/白方向及允许的 Alpha 调整，不重复尝试无效 RGB；只有用户明确要求标准/具体比值时，才以该数值检查理论可达范围。

普通文字默认共用 `textBaseColor`。优先调整适合背景的文字方向与有效 Alpha，再联合调整已允许的表面色；避免为白字达标持续压暗明亮按钮。

## 2. 普通 TEXT 节点透明度例外

允许在副本对已确认仅用于普通文字强弱、且不是业务状态的 TEXT 自身 opacity 做最小覆盖，登记 `mutationPlan.textNodeAlphaOverrides`。必须同时满足：

- 节点/全部文字区间不属于 Hero、媒体、前三名或其他精确保护；不是禁用、待解锁、不可用状态。
- 不承担蒙版、不含需要原样保留的非文字表面/材质，且未通过整体 Alpha 控制其他可见描边或 Effect。
- 仅改变该 TEXT 的 opacity 和已授权文字 Paint，不改变祖先、文案、字体、字号、字重、布局或文字区间边界；原隐藏/零贡献内容不激活。

可先将节点 opacity 归一到 1，并把原节点 Alpha 乘入各文字 Paint Alpha，使初始合成外观保持，再提高需要的 Paint Alpha 至可读目标。归一化是可选路径，不是全页统一做法；需用截图确认复杂合成没有变化。不能把节点强度统一拉满、抹掉正文层级。

记录源/副本 ID、角色及状态证据、原/目标节点 Alpha、各区间 Paint Alpha、有效强度、真实对比度、修改前后截图，以及字体/内容/几何零差异。实例不能本地覆盖时按既有解绑规则处理并重新映射。祖先或状态 Alpha 仍是结构，不使用本例外；必要时按验收中的继承约束路径处理。

## 3. 只换色不预先加载字体

[Figma 官方文字 API 指南](https://developers.figma.com/docs/plugins/working-with-text/)明确：仅改变颜色/描边的属性（例如 `fills`、`strokes`）不需要加载字体；改变内容或影响文字排版的属性才需要对应字体。保留 `figma:figma-use` 的其他调用安全要求；其一般性“文字编辑先加载字体”指引在本任务中按这一具体 API 条件执行，不能扩大到所有文字读写。

- 本 skill 默认不改排版，禁止把 `loadFontAsync`、批量加载整页字体或 `hasMissingFont=false` 作为文字换色前置门禁。
- 整段一致且无保护区间时复制 Paint 数组后赋给 `node.fills`；混合色、强调数字或混合保护时读取区间，使用 `setRangeFills(start,end,paints)` 仅写授权区间。不得为绕过 mixed 把整段样式重置。
- 不重设 `characters`、`fontName`、`textStyleId`、字号、字重、行距、字距或其他排版属性；不通过新建文字替换旧节点来换色。

### 字体错误后的恢复顺序

1. 记录真实失败 API 和错误。仅 `loadFontAsync` 失败不证明 Paint 写入失败；检查脚本是否混入了不必要的排版/内容赋值，将这些操作移除。
2. 在既有副本、既定代表白名单内选一个合法 TEXT/区间，进行一次最小纯 Paint 写入，读回 Paint、文字区间、字体、内容、几何并截图。加载器失败的调用不记为文字已换色；最小调用成功才扩展同类路径。
3. 若实际颜色写入失败，按错误类别检查实例本地覆盖、样式/变量绑定和区间权限。在保护范围允许且语义等价时，测试另一条官方颜色 API 路径或计划内副本解绑；不能通过整段覆盖跨越保护区间，也不修改共享样式/变量。
4. 若 API 路径仍失败且有已可用、可验证的原生编辑能力，可在同一节点/区间做本地颜色覆盖并同样读回审计；只有准确定位和保护区间可验证时才执行，不盲点 UI、不反复尝试同一错误。
5. 各路径按真实错误做有新依据的有限尝试；无新依据不重试。暂停受影响子树，继续不依赖它的安全工作，但不能把未处理必需文字记为通过。只有实际换色路径均不可用、无法取得必要证据或需要新权限/改变保护字体时，报告具体节点、失败 API、已尝试替代路径及需要的授权。

禁止自动换成替代字体、下载/上传/安装字体、转曲、栅格化、删除重建文字或改文案。字体缺失可记为环境警告；实际纯 Paint 写入成功且字体/内容/几何未变，不因缺字体中止换肤。
