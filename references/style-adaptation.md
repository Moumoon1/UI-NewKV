# 画风迁移规则

先比较新旧 KV：仅颜色或视觉 IP 更换不触发画风迁移；材质、体积表现、插画方式或线条语言明显变化时，才在 Phase 1 的前置检测中评估原 UI 的实际冲突，并在 Phase 2 前读取本规则。只改颜色就能协调的页面继续使用 `color-only`；不为凑风格增加效果。用户只要求分析或改 skill 时，不进行设计写入。

## 1. 判断迁移对象

在 `themeDecision` 中记录 `adaptationMode` 和 `styleAdaptationPlan`。分别观察 KV 的色彩力度、平涂/体积、光影、线条、轮廓、纹理和装饰密度。材质变化不等同于深浅模式变化：同为浅色 UI，也可能需要从写实金属转为手绘平涂。

新旧 KV 差异是评估信号，原 UI 的实际冲突决定改动范围。即使 KV 变化很大，仍协调的简洁卡片与 Tab 也保留；没有冲突则继续 `color-only`。旧 KV 无法读取时记录证据缺失，依据原 UI 与新 KV 的可见差异做最小范围判断，不虚构比较结论。

将每个目标分为：

- **保留的业务骨架**：布局、尺寸、占位、交互热区、文本、字体、状态含义，以及按钮/Tab/卡片的原有形状家族。
- **可迁移的风格外观**：主题 Icon 的画法、主题装饰插画、局部轮廓笔触、材质填充、高光/阴影组织。
- **精确保护区**：KV 上按《Figma 执行规范》第 5.4 节保护的 `protected-hero-controls` 功能入口（跨模式配色例外不授权画风迁移）、内容照片/视频、品牌资产、视频内标签与播放信息、前三名名次和对应形状，以及独立 `protected-marketing-banner` 完整子树。既有保护清单完整生效，不因迁移画风重新绘制或间接覆盖。

主题装饰图片可在语义明确时替换为与新 KV 同画风的素材；如金币仍表达收益、礼物仍表达奖励。未知图片先核实；不能将头像、作品、奖品实物或业务凭证当作装饰重画。不得用滤镜染色冒充从写实到手绘的素材迁移。

## 2. 保留形状家族，改变画法

识别实际可见载体，不能只看语义父 Frame 的 `cornerRadius`：父级可能为 0，真正按钮是子层胶囊 Vector/Rectangle。

- 原胶囊按钮继续呈胶囊，原圆角矩形保留其比例与圆角，原 Tab 的胶囊/下划线/条状指示器继续保留；不能为“卡通”把胶囊改成小圆角方块。
- 允许沿原轮廓增加轻微不规则曲线、局部笔触、内侧色边或装饰层；必须保持可辨识的原轮廓家族、原尺寸、内容安全区、热区与状态。笔触变化不能改变控件的主体形态。
- 一致性指同族控件共享画法、线条重量和状态规则，不是强制所有角色使用同一种形状。原稿不同角色的合理差异应保留；不能以参考页面形状不同为理由替换目标控件。
- 若风格效果需要改变业务骨架，则该效果不在本模式范围内，先在原形状内寻找替代画法；不默认重排页面或改字体。

## 3. 从具体 KV 提取风格特征

画风迁移不默认追求手绘感、卡通感或任何预设风格。先记录可见特征，再决定如何应用到 UI；风格名称只作描述，不能直接生成效果配方。

在 `styleAdaptationPlan.visualLanguage` 中记录以下维度及 KV 局部证据：

- **体积与表现方式**：平面、浅浮雕、立体、摄影、混合，以及空间深度如何形成。
- **材质**：光滑/粗糙、金属/玻璃/塑料/纸张等可见特征，反射、透光与表面颗粒是否成立；无法判断则标记不确定。
- **光影**：光源方向、软硬、明暗分区、高光面积与投影方式；无明显光影也是有效结论。
- **边缘与轮廓**：有无描边、边缘锐利/柔和、线宽是否变化、轮廓是否规则。无描边的 KV 不强行增加描边。
- **纹理与装饰**：是否有颗粒、网点、纸纹、笔触或其他纹理，其尺度、位置、密度与留白关系。

将上述证据映射到实际冲突角色，记录采用、简化或不迁移的理由。Icon 和主题插画可以承接更完整的表现方式；按钮需要保留识别与可读性；卡片、Tab 和内部容器只取适合其角色的特征。统一来自共有视觉特征与合理强弱，不是所有节点复制同一材质。

下表仅说明分析方向，不是风格标签对应的强制效果：

| KV 的可见特征示例 | 可能迁移到 UI 的内容 | 需要避免 |
|---|---|---|
| 写实金属或玻璃 | 有依据的体积、反射、高光与边缘表现 | 只套固定色相/透明渐变，或给所有卡片加镜面高光 |
| 柔软立体、黏土质感 | 柔和明暗、适度体积、哑光表面 | 为模仿圆润而改变原控件形状家族 |
| 平面几何或矢量插画 | 清楚色块、简洁边缘、有限层次 | 无依据增加立体反射、纹理或投影 |
| 纸艺、剪纸或拼贴 | 局部层叠关系、纸面特征与遮挡 | 把所有边缘做成撕纸或覆盖业务内容 |
| 水彩、水墨或其他笔绘 | 有证据的色彩渗化、干湿变化、笔触边缘 | 用模糊滤镜代替材质，损失小图形与文字清晰度 |
| 发光、数字空间效果 | 局部发光、明暗背景关系和光边 | 全页霓虹化、亮边侵入文字或压过操作 |

未列出的或混合画风仍按上述维度分析；不同局部可以有不同材质，不能强行归为单一风格。没有证据的效果不添加。

### 3.1 条件示例：KV 确有特殊线条或笔触时

只有观察到对应特征时，才记录 `visualLanguage.strokeLanguage` 并考虑不对称曲线、收放笔、局部缺口、复描或干刷；这些不是画风迁移的必选项。

- 两端细、中段厚可用闭合填充矢量表达；均匀 Stroke 不自动代表压感。
- 局部断笔需保留识别关键段，机械等距虚线不能代替自然断口。
- 轮廓可在原形状家族内小幅变化，不随机抖动、不侵入文字。参考若仅是自然曲线配均匀细线，无须额外添加压感或断笔。

### 3.2 按实际尺寸和角色决定实现

可采用可编辑矢量、渐变、局部效果或适合的主题素材，选择能表达目标特征的方式。图片中的材质不应被误报为几个 Paint 已完整复现；节点实现与截图观感分别核实。

小 Icon、小按钮应简化过密纹理和光影；不能缩小后留下脏点、粘连、模糊或锯齿。1:1 检查局部质量，整页检查重复密度与层级；大卡片可以保持安静，不因统一画风而堆满效果。

## 4. 材质迁移与层级

仅在本模式白名单内允许替换或关闭与新画风冲突的旧金属高光、玻璃反射、阴影、装饰 IMAGE，调整相应 Paint 类型/数量，或增加最少的独立风格矢量层。记录源层职责、替换对象及新职责；不激活原本隐藏的业务内容。

平涂风不必保留旧写实受光层次；反之，立体 KV 也不能只染色后留下扁平素材。是否成立按目标画风验收，而非按原材质层数验收。

小按钮和 CTA 使用一致的交互色家族与适用的视觉特征，CTA 的强化方式由本次 KV 决定，可以是材质、局部光影、色彩或有限装饰，也可以保持平面。仅当 KV 有对应证据时才使用偏移色块表达厚度或采用投影；无依据时不增加层叠、描边或立体感。

## 5. 裁切与真实可见范围

增加/调整阴影、描边、笔触或装饰前，读取自身及全部祖先的 `clipsContent`、蒙版、圆角、变换和边界，计算效果扩展后的真实可见范围。节点几何在容器内不代表阴影也在；自身无裁切也不代表祖先无裁切。

- 重点检查同尺寸裁切父容器、卡片底边、圆角、列表与固定底栏、靠边 Icon。外描边、模糊半径和偏移都计入可见边界。
- 优先在原安全范围内用内侧笔触、局部填充或收敛偏移实现；不合适的新增效果省略。不得默认关闭 `clipsContent`、扩大布局框或移动内容来挽救装饰。
- 有意被遮挡的礼物等装饰，与意外被切掉的按钮轮廓/阴影要分开判断。记录有意遮挡部位，确保主识别特征和信息仍完整；不能要求所有装饰全图露出。
- 在**包含实际祖先的页面截图**中验收四边及圆角；单独导出子节点可能绕过真实裁切链，不能作为唯一通过证据。

## 6. 计划、执行与验收

`styleAdaptationPlan` 至少记录：源→副本节点映射、角色、原形状家族、目标画法、允许变化属性及前后值、素材语义/来源、保护区排除、裁切链和安全边界。新增层保持绝对定位，不占 Auto Layout 空间；保留业务节点的相对顺序。计划覆盖的风格属性优先于普通换色中的材质/图片/几何保留条款，其他属性仍逐项保护。

Phase 5 用现有代表节点试做：关键数据、Icon、主要按钮/CTA、Tab、外卡和内层容器、受裁切影响的边缘。Phase 7 记录 `finalAudit.styleAdaptationAudit`，逐项验证：

1. 原稿、文本、布局、状态、内容媒体和前三名保护未变。
2. 同族形状保持原 UI，轮廓变化仅承担画风；未用空父级方形 Fill 覆盖真正载体。
3. 对照 `visualLanguage` 的证据逐项验证已迁移的体积、材质、光影、边缘与纹理，效果符合当前 KV 及业务角色；不相关维度记录不适用。不能以“加了手绘线/渐变/投影”代替风格成立；不得残留与当前 KV 冲突的上一主题画法。
4. 有新增/改变的效果经过实际祖先裁切后完整或有意遮挡，无截断、脏边、内容遮盖和热区变化。
5. 素材替换、Paint 类型/数量、隐藏旧装饰、新增矢量均在白名单中；无全树几何改写、受保护内容重画或旧隐藏文字被激活。

任一不满足，在同一副本修正对应代表/角色；未启用本模式时记录 `not-applicable`，不得引用此文件放宽普通换色范围。
